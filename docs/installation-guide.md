# Installation Guide

## Windows Installation

### Step 1

Download the latest version of the Wolof Keyboard.

### Step 2

Extract the ZIP file if necessary.

### Step 3

Run:

```
setup.exe
```

### Step 4

Complete the installation process.

### Step 5

Open Windows Settings:

Time & Language → Language & Region

### Step 6

Add or select the Wolof Keyboard layout.

### Step 7

Start typing in Wolof using the dedicated characters.

## Supported Characters

À É Ë Ñ Ó Ŋ

and other characters used in standard Wolof orthography.
